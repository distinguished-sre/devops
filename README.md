## Как проходить курс

1. **Иди по порядку.** Уроки выстроены цепочкой: каждый опирается только на пройденное. Внутри темы кнопки «назад» и «дальше» ведут по курсу без пропусков.
2. **Делай практику руками.** В каждом уроке есть шаги с командами и ожидаемым выводом. Не совпало: это повод разобраться, а не пропустить.
3. **Ломай специально.** Задание «сломай и почини» в конце практики учит главному навыку инженера: находить причину, а не симптом.
4. **Проверяй себя вопросами с собеседований.** В каждом уроке 10–12 реальных вопросов уровня junior и middle с разбором: что хотят услышать и какой ответ насторожит интервьюера.

## Сквозной проект «Заметки»

Через весь курс идёт один сервис: небольшое HTTP-приложение на Python с эндпоинтами `/healthz`, `/readyz`, `/metrics` и `/notes`, плюс встроенные поломки для тренировки (`/slow`, `/error`, `/leak`, `/burn`). Каждая тема добавляет слой:

| Тема | Что происходит с «Заметками» |
|------|------------------------------|
| 1 | Запускаем на сервере и оформляем systemd-сервисом |
| 2 | Ставим перед сервисом nginx, включаем HTTPS, разбираем путь запроса |
| 3 | Кладём в git, настраиваем CI в GitHub Actions, GitLab CI и Jenkins |
| 4 | Упаковываем в образ, поднимаем с PostgreSQL и nginx в Compose |
| 5 | Запускаем в Kubernetes, обновляем без простоя, упаковываем в Helm |
| 6 | Выносим на ВМ в Yandex Cloud, подключаем Managed PostgreSQL |
| 7 | Описываем инфраструктуру в Terraform, настройку серверов в Ansible |
| 8 | Метрики, алерты, логи, трейсы, Istio и SLO с burn rate |
| 9 | Секреты в Vault, деплой через Flux, cert-manager, CloudNativePG, canary |
| 10 | Дежурство, постмортем, восстановление из бэкапа, пробное собеседование |

К концу курса у тебя будет репозиторий `notes`, который не стыдно показать на собеседовании: код, CI, Helm-чарт, Terraform, Ansible, дашборды, алерты и runbook.

## Что понадобится

- Компьютер с 16 ГБ RAM (с 8 ГБ курс проходится, в уроках есть советы, как облегчить стенд).
- Ubuntu 24.04 или Windows с WSL2 и Ubuntu, либо macOS с Docker Desktop или Colima.
- Аккаунт на GitHub.
- Для тем 6, 7 и 10: аккаунт Yandex Cloud с пробным грантом. В уроках есть таблица соответствия сервисов AWS.

Темп: около 165 часов. По 2 часа каждый день это около трёх месяцев, по 2 часа пять дней в неделю около четырёх.
