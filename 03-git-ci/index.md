## О чём тема

История, командная работа и автоматические проверки.

Уроки идут строго по порядку: каждый опирается только на пройденное. В каждом уроке есть практика, задание «сломай и почини» и вопросы с собеседований с разбором ответов.

## Что ты сможешь после каждого урока

- **3.1** [Git: коммиты, история и ветки](01-git-basics.md): Git хранит снимки проекта, и почти любую ошибку можно откатить, если понимать индекс и reflog.
- **3.2** [Удалённые репозитории, rebase, конфликты и Pull Request](02-remotes-workflow.md): Команда работает через ветки и Pull Request, а история остаётся чистой благодаря rebase и squash.
- **3.3** [CI в GitHub Actions: проверяем каждый Pull Request](03-actions-ci.md): Каждый Pull Request автоматически проходит линтер и тесты, а красный CI не пускает код в main.
- **3.4** [Качество и безопасность в CI: сканеры, секреты, OIDC](04-quality-security-ci.md): Секреты, уязвимые зависимости и опасные workflow ловятся в CI до попадания в main.
- **3.5** [Релизы: semver, теги и GitHub Releases](05-release-flow.md): Версия это тег, тег это артефакт, а выпуск релиза повторяем и откатывается новым тегом.
- **3.6** [GitLab CI и Jenkins: тот же конвейер на других платформах](06-gitlab-ci-jenkins.md): Идея конвейера не зависит от платформы, меняется только синтаксис .gitlab-ci.yml и Jenkinsfile.
